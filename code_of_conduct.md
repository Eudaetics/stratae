# Code of Conduct

## Our Standards

This project welcomes contributions from everyone. We expect:

- **Respectful communication** - Disagree without being disagreeable
- **Constructive feedback** - Focus on ideas, not people
- **Professional behavior** - This is a technical project, keep it technical

## Unacceptable Behavior

- Personal attacks or harassment
- Trolling or deliberately inflammatory comments
- Any conduct that would be unacceptable in a professional setting

## Enforcement

As the sole maintainer, I will address any reported issues at my discretion. Violations may result in warnings, temporary bans, or permanent removal from the project.

Report issues to: [social@eudaetics.com]
